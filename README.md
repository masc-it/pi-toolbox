# pi-toolbox

Minimal, keyboard-first workflow tools for the [Pi coding agent](https://github.com/badlogic/pi-mono).

The first release provides Prompt Polish, guided feature specifications, and resumable implementation workflows through a shared terminal overlay.

The implementation follows [`docs/spec_1.md`](docs/spec_1.md).

## Development

```sh
npm install
npm run typecheck
```

Pi Toolbox uses user-operated QA checkpoints instead of an automated code-test suite.
