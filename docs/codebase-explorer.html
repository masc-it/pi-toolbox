04 / Memory is a durable pipeline

FactOne socket server serves multiple Pi sessions. SQLite stores pending work; IPC wakes tell the two consumers to check it.

Queue 1 / extraction

settled_at IS NOT NULL AND extracted_at IS NULL

Oldest exchange first. Model failure logs an error, leaves it pending, and waits for a later wake. No extraction retry timer; a failed oldest exchange can delay later ones.

Queue 2 / curation

processed_at IS NULL

Oldest eligible cwd, then rows by ID. At most 10 facts and 32 KiB of serialized fact payload per batch. Failed cwd is skipped so other projects can progress.

FactGit commit and SQLite completion are separate save points. If markProcessed fails after commit, the commit remains and the pending facts may be processed again.

05 / Data, ownership, and lifetime

FactWorkflow content is temporary. Once submitted to Pi, a prompt can be captured and saved by Memory.

Relational spine

SQLitememory_exchangesid: INTEGER / bigint
1 exchange owns N messages via exchange_id→
SQLitememory_messagesUnique (exchange_id, position)
SQLitememory_exchanges
1 exchange produces 0..N facts via exchange_id→
SQLitememory_queuePending / processed facts

A partial unique index limits each Pi session to one open exchange. IDs use bigint; messages follow position order. Extraction can produce zero facts.

06 / Boundaries and tradeoffs

Facts describe the source. Inferences explain tradeoffs. Recommendations are listed separately.

Screen / workflow boundary

FactToolboxScreen renders lines and handles input. ToolboxScreenHost exposes navigation, close, and render requests. Factories inject workflows and callbacks.

InferenceWorkflows can be checked without a terminal. Screens remain responsible for async state, cancellation, and focus.

src/ui/screen.tscreateToolboxScreens

Two kinds of model integration

FactPolish uses the in-process registry and completeSimple. Context and Memory spawn headless Pi, parse JSON-line events, and return the last assistant text.

InferenceThe direct call is small and tool-free; subprocess agents reuse Pi tools but add process startup, CLI, and output-parsing contracts.

WorkflowModelClient.completeTextrunHeadlessAgent

Language adapters / shared runner

FactBoth complexity adapters share the same screen and runComplexityAnalyzer, supplying invocation and language-specific errors. JS/TS additionally supplies a five-minute timeout.

InferenceReuse aligns UI behavior. Each analyzer has its own metrics and scores.

src/workflows/complexity-runner.tssrc/ui/screens.ts

Shared service / session ordering

FactThe server serializes requests per session; consumers run outside Pi. SQLite uses WAL, a busy timeout, foreign keys, and strict tables. Request receipts make repeated IDs idempotent for durable mutations.

InferenceThis isolates curation latency from Pi sessions and survives crashes. It introduces socket startup, migration, supervision, and multi-store recovery complexity.

Behavior you might not expect

  • FactEvery overlay loads config and Memory status. A status failure blocks all screens, including Polish. Source: ToolboxOverlayController.open.
  • FactThe Memory footer shows status fetched when the overlay opens; it stays unchanged. Source: ToolboxOverlay.memoryStatus.
  • FactContext Finder relies on read-only instructions. It exposes bash with --no-approve. normalizeReferenceList formats bullets without verifying paths or symbols. Source: src/workflows/context-finder.ts.
  • FactContext Finder does not pass --no-extensions; Memory extractor and curator do. Source: their argument builders.
  • FactCapture failures silently disconnect the client. Later operations can reconnect; failed captures are not replayed. Receipts support explicit same-ID resends. Source: MemoryClientRuntime.capture, MemoryServerConnection.request.
  • FactPolish Accept and Copy shortcuts are checked before the generating-state guard. An existing edited result can be accepted/copied during regeneration. Source: PromptPolishScreen.handleInput.
  • FactJS/TS parsing is syntax-only; it does not load target dependencies or tsconfig. No Vue, Svelte, Flow, or compiler-plugin syntax. Complexity ranks refactoring candidates; it does not establish correctness or runtime performance. Source: scripts/javascript-typescript-complexity/source-files.mjs and README.md.

Recommendations / not implemented

  • RecommendationFor enforced read-only access, replace bash with constrained search tools.
  • RecommendationAllow prompt tools to open when Memory status is unavailable.
  • RecommendationFor unattended recovery, add extraction backoff and report blocked exchanges.
